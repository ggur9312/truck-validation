# 트럭검증 북마크릿

WMS "집품 현황 조회" 페이지에서 토트 바코드 스캔 → 자동 조회 → 트럭/택배 판별 → 상품 검증 → 운송장 생성/재출력까지 자동화하는 북마크릿.

## 설치

1. `dist/bookmarklet.txt` 파일 내용을 전부 복사합니다.
2. 브라우저 북마크바에 새 북마크를 추가합니다.
3. 이름은 원하는 대로(예: "트럭검증"), URL 필드에 복사한 내용을 그대로 붙여넣고 저장합니다.
   - Chrome은 주소창에 `javascript:`로 시작하는 텍스트를 붙여넣으면 보안상 `javascript:` 부분을 자동으로 지웁니다. 북마크 **편집 화면의 URL 필드**에 붙여넣을 때는 문제없이 저장되며, 혹시 지워졌다면 맨 앞에 `javascript:`를 직접 타이핑해 넣으면 됩니다.
4. WMS 집품 현황 조회 페이지에서 방금 만든 북마크를 클릭하면 실행됩니다.

## 사용법

1. 북마크 클릭 → 화면 가운데 설정창이 뜹니다. **활성화** 버튼을 누르면 자동화가 시작됩니다.
2. 토트 바코드를 스캔하면 자동으로 조회되고, 첫 번째 결과 행 기준으로 트럭/택배 여부와 상품 정보를 가져옵니다.
3. 상품검증 모달이 뜨며 실물 상품 바코드를 스캔해 수량을 맞춥니다. 화면 하단의 바코드를 스캔하면 검증을 건너뛸 수 있습니다.
4. 검증이 끝나면:
   - **택배**: WMS 운송장생성 모달이 자동으로 열립니다. 우측 상단에 뜨는 바코드를 스캔하면 운송장이 생성됩니다.
   - **트럭**: 검증 모달만 닫히고 종료됩니다.
5. 운송장 생성 후 자동으로 재조회되며, 좌측 상단에 "운송장 재출력" 바코드가 뜹니다. 스캔하면 재출력까지 자동 완료됩니다.
6. 좌측 하단 톱니바퀴(⚙) 버튼으로 언제든 설정창을 다시 열 수 있습니다.

바코드 스캐너는 키보드 입력으로 동작하므로, 화면에 뜨는 바코드도 실제 스캐너로 스캔해야 합니다(마우스 클릭 아님).

## 개발

```
npm install       # 스모크 테스트에 필요한 playwright 설치(선택)
node build.js     # src/bookmarklet.js -> dist/bookmarklet.txt 생성
node test/code128.test.js   # CODE128 인코더 단위 테스트
node test/smoke.js          # 택배(운송장생성/재출력) 시나리오 e2e 스모크 테스트
node test/smoke_truck.js    # 트럭 시나리오 e2e 스모크 테스트
```

`test/fixture.html` + `test/server.js`는 실제 WMS 구조를 흉내 낸 목업 페이지로, 실제 사내망 없이도 전체 흐름을 검증합니다.

## 실제 WMS 셀렉터가 다를 경우

`src/bookmarklet.js` 최상단 `SEL`, `CTRL` 객체에 모든 DOM 셀렉터가 모여 있습니다. 실제 페이지 구조가 문서화된 내용과 다르면 이 부분만 수정하면 됩니다.

| 상수 | 설명 |
|---|---|
| `SEL.toteInput` | 토트 바코드 입력창 |
| `SEL.searchBtn` | 조회 버튼 |
| `SEL.dateRange` | 기간 입력 커스텀 엘리먼트 |
| `SEL.resultTable` | 집품 현황 결과 테이블 |
| `SEL.waybillDialog` / `waybillSubmit` | WMS 운송장생성 모달 / 생성 버튼 |
| `SEL.reprintModal` / `reprintAllBtn` | WMS 운송장 재출력 모달 / 전체출력 버튼 |

첫 행 td 인덱스(링크 위치, 상세페이지 테이블 구조)는 `processRow`, `parseDeliveryType`, `parseToteAndProducts` 함수 안에 하드코딩되어 있습니다.

## 참고: 가상 바코드 동작 원리

바코드 스캐너는 대부분 키보드 에뮬레이션 장치로 동작합니다. 화면에 CODE128로 그려진 "제어 코드"(`TVCTL_SKIP`, `TVCTL_WAYBILL`, `TVCTL_REPRINT`)를 실제 스캐너로 스캔하면, 그 문자열이 현재 포커스된 입력창에 그대로 타이핑됩니다. 스크립트가 이를 감지해 해당 입력창에 남은 문자를 지우고 원래 의도한 동작(검증 건너뛰기, 운송장생성 클릭, 재출력 클릭)을 실행합니다. 실제 상품/토트/박스 바코드는 이 제어 코드와 겹치지 않는 값이므로 정상적으로 각자의 입력창에 입력됩니다.
